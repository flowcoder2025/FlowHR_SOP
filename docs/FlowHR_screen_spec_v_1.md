# HR SaaS 제품 명세 및 화면 명세 v1.0

## 0. 문서 목적

본 문서는 HR SaaS를 이미지 생성, 와이어프레임, PRD, 개발 백로그로 확장하기 전에 필요한 제품 구조와 화면 명세를 정리한 기준 문서이다.

본 문서의 핵심 목적은 다음과 같다.

- 운영사 / 테넌트 관리자 / 직원 3권한 구조 확정
- 제품의 주요 기능 범위 정의
- 화면 목록과 화면별 역할 정의
- CRUD/권한 매트릭스 정의
- 화면별 테이블, 필터, 버튼, 상태값 정의
- 향후 이미지 재생성 및 개발 설계의 기준 제공

## 1. 제품 개요

### 1-1. 제품명

가칭: **HR SaaS**

### 1-2. 제품 정의

소규모 사업장과 중소기업이 직원, 조직, 근태, 휴가, 결재, 급여명세서, 문서, 증명서, 알림을 하나의 시스템에서 관리할 수 있도록 하는 **멀티테넌트 HR 운영 SaaS**.

### 1-3. 제품 포지션

기존 저가형 HR SaaS처럼 단순 셀프 사용만 제공하는 것이 아니라, 고객사의 조직 구조, 근무제, 휴가 정책, 승인라인, 문서 양식 등을 초기에 세팅해주는 **세팅형 HR SaaS**.

### 1-4. 판매 메시지

> 초기에는 고객사에 맞춰 조직도, 근무제, 휴가정책, 승인라인, 문서양식을 세팅하고, 이후에는 직원 1인당 월 2,500원의 낮은 비용으로 운영할 수 있는 HR SaaS.

| 항목 | 기준 |
|---|---:|
| 초기 구축비 | 5,000,000원 |

| 항목 | 의미 |
|---|---|

## 5. 공통 시스템 명세

| 화면/기능 | 목적 | 주요 기능 |
|---|---|---|
| 로그인 | 사용자 인증 | 이메일/비밀번호 로그인, 2FA 진입, 권한별 대시보드 이동 |
| 비밀번호 찾기 | 계정 복구 | 이메일 인증, 비밀번호 재설정 |
| 최초 계정 활성화 | 초대 사용자 계정 활성화 | 비밀번호 설정, 약관 동의, 계정 활성화 |
| 2단계 인증 | 보안 강화 | 인증코드 입력, 복구코드, 신뢰기기 설정 |
| 권한 없음 | 접근 제한 안내 | 이전 화면, 홈 이동 |
| 오류/점검 화면 | 장애/점검 안내 | 403, 404, 500, 점검 중 안내 |
| 알림 센터 | 알림 통합 조회 | 읽음 처리, 전체 읽음, 관련 화면 이동 |
| 파일 업로드/미리보기 | 문서/증빙 관리 | PDF, 이미지, XLSX, CSV 업로드/미리보기/다운로드 |
| 엑셀 가져오기/내보내기 | 대량 데이터 처리 | 양식 다운로드, 업로드 검증, 오류 행 다운로드 |
| 감사 로그 기록 | 보안/추적 | 주요 생성/수정/삭제/승인/반려 이벤트 기록 |
