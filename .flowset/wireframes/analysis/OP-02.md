## 5. API 매핑 (api/operator.md)

```
GET    /api/v1/operator/tenants?page&pageSize&sort&filter[status]&filter[plan]&q
POST   /api/v1/operator/tenants                                   # OP-04에서 호출
PATCH  /api/v1/operator/tenants/:id                               # 상태/요금제/관리자 변경
DELETE /api/v1/operator/tenants/:id                               # archived (soft delete)
POST   /api/v1/operator/tenants/export                            # Excel
POST   /api/v1/operator/tenants/:id/change-admin                  # 관리자 변경
```

## 8. Phase 7 변환

- React-Hook-Form (필터 패널 state) + TanStack Query (GET /api/v1/operator/tenants)
- 페이지네이션: react-query keepPreviousData + URL ?page= 동기화
- 행 액션 메뉴: shadcn/ui DropdownMenu
- Excel 내보내기: 서버 SheetJS → Signed URL 응답 → 클라이언트 window.open
- Realtime: Supabase channel `tenants` 구독 → 신규/변경 시 invalidate
- 권한 음성: 미들웨어 `users.role.startsWith('operator_')` 체크 → 403 redirect
