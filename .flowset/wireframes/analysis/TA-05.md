
## 8. Phase 7 변환

- shadcn/ui DataTable + 시간 컬럼 monospace + tabular-nums
- TanStack Query — `attendances` 필터 무한 스크롤 또는 페이지네이션
- 수동 등록 모달 — react-hook-form + zod (사유 필수)
- 행 액션: shadcn/ui DropdownMenu (상세 / 수정 / 삭제)
- KPI realtime: Supabase channel `attendances:tenant_id={id}` 구독
- 자동 누락 처리: cron 23:59 `UPDATE attendances SET status='missing' WHERE clock_in_at IS NOT NULL AND clock_out_at IS NULL AND DATE(clock_in_at) < CURRENT_DATE`
