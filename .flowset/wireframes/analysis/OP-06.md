## 4. API

```
GET   /api/v1/operator/billing/invoices?month&status&plan&overdue
POST  /api/v1/operator/billing/batch-issue                # 월 일괄 발행
PATCH /api/v1/operator/billing/invoices/:id/mark-paid     # 결제완료 처리
POST  /api/v1/operator/billing/invoices/:id/refund        # 환불 (super)
GET   /api/v1/operator/billing/invoices/:id/pdf           # 인보이스 PDF
POST  /api/v1/operator/billing/invoices/:id/tax-invoice   # 세금계산서 발행
POST  /api/v1/operator/billing/export
```
