## 8. Phase 7 변환

- TanStack Query — `/me/dashboard` 단일 호출로 KPI + 카드 5종 batch fetch
- Supabase Realtime — `realtime:attendances:me`, `realtime:approvals:me`, `realtime:notifications:me` 구독 → KPI invalidate
- 출퇴근 IndexedDB 큐 — `idb-keyval` 또는 `workbox-background-sync`로 오프라인 큐 + 네트워크 복귀 시 자동 sync
- GPS — `navigator.geolocation.getCurrentPosition` + 권한 거부 시 정책 분기 (회사 차단 vs 위치 없이 진행)
- PWA push — Service Worker subscribe + `users.push_subscription` 저장 + iOS 16.4+ 안내
- 실시간 시계 — `setInterval(1000)` (페이지 visible 시만)
- Skeleton: shadcn/ui Skeleton + Suspense fallback
- 누락 banner — 서버 측 cron이 attendances.status='누락' 갱신 후 응답에 포함
