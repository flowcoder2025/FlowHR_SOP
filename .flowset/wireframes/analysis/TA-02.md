## 5. API 매핑 (api/tenant.md — TA-02 §7 8 엔드포인트)

```
GET    /api/v1/tenant/employees?page&sort&filter&q
POST   /api/v1/tenant/employees                            # 단건 등록
POST   /api/v1/tenant/employees/bulk                       # 일괄 (Excel parsed)
PATCH  /api/v1/tenant/employees/:id
POST   /api/v1/tenant/employees/:id/change-status          # 사유 필수
POST   /api/v1/tenant/employees/:id/send-invite
POST   /api/v1/tenant/employees/export
GET    /api/v1/tenant/employees/bulk-template              # Excel 양식
```

## 6. 권한 매트릭스 (Gherkin 정합)

- `tenant_super`: CRUD/E/N (전체 + 퇴사 처리)
- `tenant_hr_admin`: CRU/E/N (삭제는 퇴사 처리만)
- `tenant_manager`: R 소속팀만 (state=filtered 자동 적용 + "직원 등록" 버튼 숨김)
- `employee`: R 본인만 (실질 EM-09로 redirect 권장)
- 권한 음성: tenant A 관리자가 tenant B 직원 ID로 PATCH → RLS 403

## 8. Phase 7 변환

- React-Hook-Form (필터 패널 + 등록 모달) + TanStack Query (GET /api/v1/tenant/employees)
- 일괄 업로드: react-dropzone + SheetJS parse → POST /bulk → 부분 실패 행 UI
- 모달 (직원 등록): shadcn/ui Dialog + react-hook-form + zod 검증 (이메일/사번 중복)
- 권한 음성: middleware role check + RLS policy `tenant_id = current_setting('app.tenant_id')`
- 행 액션 메뉴: shadcn/ui DropdownMenu (상세 / 수정 / 상태변경 / 초대발송)
- Excel 내보내기: 서버 SheetJS → Signed URL → window.open
- Realtime: Supabase channel `employees:tenant_id={id}` 구독 → 신규/변경 시 invalidate
