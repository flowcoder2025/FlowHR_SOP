
## 6. 권한 매트릭스

- `employee`: CRU/Cancel 본인 (state=default)
- 다른 직원의 leave_id로 GET → 403 (RLS)
- 잔여 부족 → server validation 403 (`INSUFFICIENT_LEAVE_BALANCE`)
- 증빙 필수 유형 (병가) 미첨부 → 422 (`EVIDENCE_REQUIRED`)

## 8. Phase 7 변환

- React Hook Form + Zod schema (`LeaveRequestSchema`)
- 자동 계산 — `useMutation('/leaves/calculate-days')` 또는 client-side date-fns (주말/공휴일 제외 회사 설정)
- 결재라인 미리보기 — `useQuery('/leaves/preview-approval-line', { type, days })` debounce 500ms
- 임시저장 — `localStorage` + 서버 draft API (`POST /draft`) 동기 — 페이지 이탈 시 dirty check
- 잔여 검증 — server-side `INSUFFICIENT_LEAVE_BALANCE` 422 응답 처리
- 결재 흐름 시작 — `leaves` INSERT + `approvals` + `approval_steps` 동시 INSERT (transactional)
