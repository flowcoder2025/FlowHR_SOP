## 8. Phase 7 변환

- PWA sticky 액션 — `position: fixed; bottom: env(safe-area-inset-bottom);`
- 승인 처리: `POST /:id/approve` → optimistic update + 다음 단계 알림 (Realtime)
- 반려 모달: shadcn/ui Dialog + react-hook-form (사유 textarea 필수)
- 의견 작성: 인라인 textarea + 시간순 timeline 갱신
- Realtime: `leaves:id={id}` channel — 다른 결재자 처리 시 즉시 상태 갱신
- 잔여 부족 차단은 EM-03 단계에서 처리 (PRD §시나리오 8)
