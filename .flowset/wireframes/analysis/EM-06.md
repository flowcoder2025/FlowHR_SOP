## 5. API 매핑

```
GET  /api/v1/me/payslips?year                  # 연도별 목록
GET  /api/v1/me/payslips/:id                   # 상세 (지급/공제)
GET  /api/v1/me/payslips/:id/download          # PDF (Signed URL 15분)
POST /api/v1/me/payslips/:id/acknowledge       # 열람 확인
```

## 6. 권한 매트릭스

- `employee`: R/E 본인 (state=default)
- 다른 직원의 payslip_id로 GET → 403 (RLS `documents.employee_id = auth.uid()` AND `sub_type='payslip'`)
- 상세 모달 진입 시 자동 `documents.viewed_at` 갱신 → status=viewed
- 수동 열람 확인 → status=acknowledged (+acknowledged_at)
- PDF 다운로드 → audit_logs 기록 (Signed URL 15분 만료)

## 8. Phase 7 변환

- PDF 생성 — Puppeteer 또는 React-PDF (`@react-pdf/renderer`) → Supabase Storage 업로드
- Signed URL — Supabase Storage `createSignedUrl(15 * 60)` (15분)
- 7일 미열람 cron — 카카오 알림톡 재발송 + SMS 폴백
- 모달 진입 시 즉시 `useMutation('/acknowledge')` 호출 (자동 열람)
- audit_logs — 다운로드 시 `{ action: 'payslip_download', resource_id, ip }` 기록
