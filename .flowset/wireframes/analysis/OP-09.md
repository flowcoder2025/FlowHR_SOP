## 1. PRD 매핑

| PRD | 구현 |
|------|------|
| 필수 기간 필터 (오늘/7/30/90/커스텀) | filter-period chip 5개 + active 표시 |
| 테넌트/이벤트유형/사용자/결과 필터 | 5 filter-section (autocomplete + checkbox 그룹) |
| 9 이벤트 카테고리 토글 (auth/tenant/employee/attendance/leave/approval/document/setting/feature_flag) | event 유형 checkbox 9개 |
| 10 컬럼 테이블 | 발생일시/테넌트/사용자/역할/이벤트/대상/결과/IP/액션 (drawer 트리거) |
| 상세 보기 (before/after diff + user-agent + 전체 메타) | 우측 480px drawer + diff-before/after highlight + Raw JSON |
