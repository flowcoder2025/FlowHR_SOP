## 5. API / 운영 매핑

| 상태 | 트리거 |
|------|-------|
| 404 | Next.js notFound() 또는 라우터 fallback |
| 500 | 서버 throw + Sentry capture + request_id 응답 |
| maintenance | OP-11 시스템 설정에서 토글, `system_settings.maintenance_mode = true` 시 미들웨어가 모든 요청 인터셉트 (operator_super 제외) |
| 503 | rate-limit 또는 upstream 장애 — retry_after 헤더 |
| network | axios/fetch error event — offline 이벤트 |

## 7. Phase 7 변환

- Next.js `app/not-found.tsx` (404), `app/error.tsx` (500 — error boundary)
- maintenance mode: 미들웨어에서 `system_settings` 조회 → 우회 (super 제외) → /maintenance redirect
- 503 — fetch interceptor에서 retry-after 파싱 → 자동 retry 1회 + 실패 시 화면
- network — `window.addEventListener('offline', ...)` + 토스트 알림
