## 5. API 매핑

```
GET  /api/v1/me/certificate-requests?status&page
POST /api/v1/me/certificate-requests
GET  /api/v1/me/certificate-requests/:id
POST /api/v1/me/certificate-requests/:id/cancel
GET  /api/v1/me/certificate-requests/:id/download    # 발급 PDF
```

## 6. 권한 매트릭스

- `employee`: C/R/Cancel 본인 (state=default)
- 다른 직원의 cert_id로 GET → 403 (RLS `certificate_requests.employee_id = auth.uid()`)
- 취소 가능 — `status='pending'`만 (HR 처리 시작 후 차단)
- 발급 완료 PDF — Signed URL 발급 + audit_logs 기록
- HR 반려 → status=rejected + 사유 표시
