```
GET /api/v1/me/leaves?status&type&from&to&page

GET /api/v1/me/leaves/:id
POST /api/v1/me/leaves/:id/cancel
```

## 6. 권한 매트릭스

- `employee`: R 본인 (state=default)
- 다른 직원의 leave_id로 GET → 403 (RLS)
- 승인 전 취소 → status=cancelled 즉시 + 결재자 알림
- 승인 후 취소 → 사유 필수 + 별도 결재 흐름 (관리자 승인 후 잔여 회복)

## 8. Phase 7 변환

- `recharts` 또는 `visx` PieChart로 chart-placeholder 교체 — 본 placeholder는 시각 검수용
- TanStack Query 병렬 (`leaves`, `leave-balances` 동시)
- 만료 cron — 30일/7일 전 알림 발송 (`scheduled_jobs` Supabase Edge Function)
- 취소 흐름 — pending → 즉시 cancelled / approved → 사유 필수 + 결재 라우팅
- 권한 — RLS `leaves.employee_id = auth.uid()`
