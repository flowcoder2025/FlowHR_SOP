## 8. Phase 7 변환

- recharts/visx (LineChart/BarChart/DonutChart/StackedBarChart) → inline SVG 대체
- TanStack Query — KPI 6 병렬 + 차트 4 순차 fetch (PRD §3 "KPI 병렬, 차트 순차" 정합)
- Supabase Realtime — `realtime:leaves:tenant`, `realtime:attendances:tenant`, `realtime:approvals:tenant` 구독 → 카드 invalidate
- 권한 음성: middleware `users.role === 'employee'` → `/me` redirect
- manager 자기 팀 KPI: server-side filter `WHERE department_id IN (manager's dept tree)`
- Skeleton: shadcn/ui Skeleton + suspense fallback
