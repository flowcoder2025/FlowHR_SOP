## 8. Phase 7 변환

- TanStack Query — `useAttendanceQuery({ from, to })` + 무한 스크롤 또는 page query
- GPS clock-in — `navigator.geolocation` + `accuracy < 50m` 검증 + 회사 좌표 비교 (`haversine`)
- 오프라인 큐 — `workbox-background-sync` 또는 IndexedDB queue
- 회사 정책 분기 — `tenant_settings.gps_required` + `tenant_settings.remote_radius_km`
- 누락 자동 처리 — daily cron 23:59 → `UPDATE attendances SET status='누락' WHERE clock_out IS NULL`
- 수정 요청 → TA-06 라우팅 — `attendance_modifications` INSERT + Realtime broadcast
