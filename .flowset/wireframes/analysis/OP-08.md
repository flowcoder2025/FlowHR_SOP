## 1. PRD 매핑

| PRD | 구현 |
|------|------|
| 운영사 화면 10 컬럼 테이블 → Master-Detail 변형 | 좌측 ticket-list (360px) + 우측 ticket-detail |
| 우선순위 P0~P3 + SLA 색상 코딩 | badge-danger/warning/muted + SLA D-0 4h danger color |
| 응답 스레드 (사용자/운영사/내부 메모) | ticket-thread-msg .from-tenant / .from-operator / .internal 3 variant |
| 내부 메모 토글 (테넌트에게 안 보임) | reply form .reply-internal-toggle 체크 → state=internal_memo |
| 담당자 지정/상태 변경/우선순위 변경 | 상세 헤더 + 액션 버튼 행 |
| 해결로 변경 (closed) | 상태 변경 → ticket-closed-banner + reply-form hidden |

## 2. 상태 (5)

| 키 | state |
|---|-------|
| 1 | list (목록만 — ticket-detail-empty hero) |
| 2 | detail (디폴트 — 스레드 4 메시지 + 답변 폼 + 액션) |
| 3 | reply (답변 작성 폼 활성) |
| 4 | internal_memo (warning 배경 + 내부 메모 모드) |
| 5 | closed (해결 banner + reply-form hidden) |
