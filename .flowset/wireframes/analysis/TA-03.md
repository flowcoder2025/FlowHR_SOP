## 5. API 매핑 (api/tenant.md — TA-03 §7)

```
GET   /api/v1/tenant/employees/:id                  # 종합 (헤더 + 모든 탭 데이터 lazy)

POST  /api/v1/tenant/employees/:id/resign

```

## 6. 권한 매트릭스 (Gherkin 정합)

- `tenant_super`: R/U/D/L 전체 9 탭 (퇴사·삭제 권한 포함)
- `tenant_hr_admin`: R/U/L 9 탭 중 퇴사 불가
- `tenant_manager`: R 소속팀 일부 — 기본정보 / 근태 / 휴가 탭만 (5 탭 비공개) → state=empty (i-lock)
- `employee`: R 본인 일부 (기본정보 + 본인 변경이력 read-only) — `/me/profile`로 redirect 권장
- 민감 정보 (계좌번호) 변경: 2FA 재인증 필수 (Phase 7 modal)

## 8. Phase 7 변환

- shadcn/ui Tabs (orientation=horizontal) + URL ?tab=X 동기화
- react-hook-form (기본/인사 인라인 수정) + zod 검증
- 권한 게이팅: `usePermission(role, tab)` hook — 비공개 탭은 메뉴에서 숨김 또는 disabled
- 민감 정보 변경: shadcn/ui Dialog + 2FA 입력
- 퇴사 처리: confirmation modal + 퇴직일 입력 + 잔여연차 정산 안내
- 근태 / 휴가 탭: TA-05 / EM-04 임베드 (직원 단일 필터)
- 변경이력: Supabase audit_logs 쿼리 + diff 컴포넌트
- Realtime: `realtime:employees:id={id}` 구독 → 헤더 카드 KPI 즉시 갱신
