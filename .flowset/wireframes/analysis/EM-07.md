## 5. API 매핑

```
GET  /api/v1/me/documents?type&status&from&to&page
GET  /api/v1/me/documents/company-wide                # 회사 공지 문서
GET  /api/v1/me/documents/:id/preview
GET  /api/v1/me/documents/:id/download
POST /api/v1/me/documents/:id/acknowledge
```

## 6. 권한 매트릭스

- `employee`: R/E 권한 문서 (내 문서 = `documents.employee_id = auth.uid()` / 회사 = `documents.scope='company-wide' AND tenant_id = auth.tenant_id`)
- 다른 직원의 document_id 직접 GET → 403 (RLS)
- 만료된 문서 → "만료됨" 배지 + 다운로드는 가능 (감사 추적용)
- 회사 문서 신규 버전 발행 → 직원에게 알림 + 열람 의무 일정 (있을 경우)
