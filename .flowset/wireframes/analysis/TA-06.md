## 6. 권한 매트릭스 (Gherkin 정합)

- `tenant_super` / `tenant_hr_admin`: R/A/E/N (전체 단계 승인)
- `tenant_manager`: R/A 소속팀만 (1차 승인)
- `employee`: C/R/Cancel 본인만 (승인 전 취소 가능)
- 증빙 필수 정책 (TA-13에서 토글) — false면 증빙 없이 제출 가능하나 결재자에게 "증빙 없음" 표시

## 7. 검증 (시각 검수)

- [ ] 5 상태 토글 — 목록 / loading / 상세 drawer 열림 / 빈 / 오류
- [ ] filter-bar chip — 대기(8) is-active variant
- [ ] 테이블 첫 행 warning-bg 강조 (대기 + SLA 임박)
- [ ] diff-row — 원기록 line-through / 요청값 success 색상 + 굵게
- [ ] 결재 라인 단계 표시 + 회신 시간 (0h)
- [ ] drawer 액션 — 승인(primary) / 반려(danger) / 의견(ghost icon)
- [ ] 증빙 첨부 — i-paperclip + filename + size
- [ ] empty 상태 — i-check + 처리 완료 안내
