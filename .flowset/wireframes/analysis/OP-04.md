## 5. API 매핑

```
GET    /api/v1/operator/plans
POST   /api/v1/operator/tenants/check-domain
POST   /api/v1/operator/tenants/check-business-number
POST   /api/v1/operator/tenants/drafts
GET    /api/v1/operator/tenants/drafts/:draftId
POST   /api/v1/operator/tenants                     # 트랜잭션
POST   /api/v1/operator/tenants/:id/send-invite     # 재발송
```

응답 envelope + `fields` 객체로 필드별 오류 (zod refine 매핑).

## 6. 검증

- [ ] 7 stepper — completed(✓) / active(accent) / pending(muted) 시각 분기
- [ ] 5 상태 토글 (1~5)
- [ ] step1 input 2 cols grid + 사업자번호 실시간 검증 placeholder
- [ ] step3 요금제 카드 3종 — 선택됨 강조 + 월 청구액 자동 계산
- [ ] step5 모듈 토글 is-on / OFF variant
- [ ] step7 review-table 8행 + 자동 실행 안내 banner
- [ ] step7-failed warning + 재발송 / 목록 CTA

## 7. Phase 7 변환

- React-Hook-Form `useFormContext` + step별 sub-form
- zod schema: `companyInfoSchema`, `domainSchema`, `planSchema`, `adminSchema`, `modulesSchema`, `initialDataSchema`
- `useStepWizard` 커스텀 hook (current step + canGoNext + persist draft)
- 트랜잭션: Supabase Edge Function `create-tenant-transaction` (모든 INSERT + invite)
- 초대 실패 시 부분 commit: tenants는 INSERT, status=pending_invite, 재시도 가능
- 자동 저장: 입력 onChange debounce 2s → POST drafts
