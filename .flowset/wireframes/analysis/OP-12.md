## 1. PRD 매핑

| PRD | 구현 |
|------|------|
| 5 탭 (기본정보/보안/활성세션/알림/활동) | tabs-row 5 + state별 active 분기 |
| 운영사 보안 정책 banner (2FA 강제 + 12자 PW + 90일) | auth-alert-warning 상단 |
| 비밀번호 12자+ 4종 조합 + 직전 5회 다름 | security 탭 form-section + input + 정책 안내 |
| 2FA 비활성화 불가 | "2FA — 활성" + 비활성화 버튼 없음 |
| 복구 코드 8개 + 재발급 | 남은 7/8 표시 + 재발급 CTA |
| 최근 로그인 이력 (30일) — 이상 IP 차단 | table 4행 + 베이징 IP 차단 row warning |
| 본인 세션 + 다른 operator_staff 세션 종료 (super 전용) | session-row 2 (current/모바일) + 3 (staff is-staff variant + 강제 종료 btn-danger) |
| 강제 종료 시 사유 입력 + audit + 슬랙 알림 | force_logout 모달 + textarea + danger 확정 |
| 시스템 장애 알림 OFF 불가 | 알림 카테고리 "P0/P1 — OFF 불가" 라벨 |

## 4. API (api/auth.md + api/operator.md)

```
GET    /api/v1/operator/me                              # 본인 정보
PATCH  /api/v1/operator/me                              # 닉네임/표시이름
POST   /api/v1/operator/me/password                     # 비밀번호 변경
POST   /api/v1/operator/me/two-factor/regenerate-qr     # QR 재발급
POST   /api/v1/operator/me/two-factor/recovery-codes    # 8 코드 재발급
GET    /api/v1/operator/me/sessions                     # 본인 세션
DELETE /api/v1/operator/me/sessions/:sid                # 본인 세션 종료
GET    /api/v1/operator/staff-sessions                  # super: 다른 staff 세션
POST   /api/v1/operator/staff-sessions/:sid/terminate   # super: 강제 종료 + reason + audit
GET    /api/v1/operator/me/login-history?days=30
```

## 5. 검증

- [ ] 5 상태 토글
- [ ] sessions 탭 — current(accent bg) / 모바일(default) / staff(warning bg) 3 variant
- [ ] 강제 종료 btn-danger + 모달 (사유 필수 + super 전용 안내)
- [ ] 로그인 이력 차단 row warning IP + danger badge
- [ ] 2FA 비활성화 버튼 없음 (PRD 정책)

## 6. Phase 7 변환

- 5 탭 ?tab= URL 동기화
- 강제 종료: Supabase admin signOut(userId, sessionId) + audit insert + 슬랙 webhook
- 비밀번호 변경 시 모든 다른 세션 invalidate (현재 세션은 유지)
- 이상 로그인 감지: edge function + geoip + IP 패턴 학습 (v1.1 기획)
