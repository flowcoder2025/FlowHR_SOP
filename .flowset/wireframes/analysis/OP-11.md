```
GET    /api/v1/operator/system-settings
PATCH  /api/v1/operator/system-settings              # super only
POST   /api/v1/operator/system-settings/maintenance  # 토글 + audit
POST   /api/v1/operator/system-settings/backup/now   # 즉시 백업
GET    /api/v1/operator/system-settings/backup/history
POST   /api/v1/operator/system-settings/backup/:id/restore  # 위험
```
