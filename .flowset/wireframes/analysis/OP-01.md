## 4. 인터랙션 동선

### 4-1. 진입 흐름 (09-routing §3 라우팅 매트릭스)
```
/login (CM-01) → 인증 + JWT operator_super
  → /operator (OP-01 본 화면)
  → first_login_at IS NULL → CM-22 온보딩 투어 모달 자동 시작 (operator 4-step)
```

### 4-2. KPI 카드 → 도메인 드릴다운 (PRD §4 onDrillDown)
```
"전체 테넌트" 카드 클릭 → /operator/tenants (OP-02)
"활성 테넌트" 카드 클릭 → /operator/tenants?status=active (OP-02 필터링)
"총 사용자" 카드 클릭 → /operator/reports?metric=user_count (OP-10)
"MRR" 카드 클릭 → /operator/billing (OP-06)
"미수금" 카드 클릭 → /operator/billing?status=overdue (OP-06 필터링)
"오픈 티켓" 카드 클릭 → /operator/tickets?status=open (OP-08)
"시스템 상태" 카드 클릭 → /operator/system-settings#status (OP-11)
```

### 4-3. 액션 버튼
```
"신규 테넌트 등록" → /operator/tenants/new (OP-04 마법사)
"리포트 다운로드" → POST /api/v1/operator/dashboard/export → PDF/Excel Signed URL
"티켓 보기" → /operator/tickets (OP-08)
"청구 보기" → /operator/billing (OP-06)
```

### 4-4. 글로벌 컴포넌트 인터랙션
```
검색바 클릭 → "v1.1 출시 예정" 토스트 (CM-18 △ 정책)
도움말 ? 클릭 → CM-19 슬라이드 패널 (현재 화면 = OP-01 가이드)
종 🔔 클릭 → CM-17 미니 드롭다운 (최근 10건 + "전체 보기" → /operator/notifications)
프로필 아바타 클릭 → CM-16 드롭다운 (위 §3 메뉴)
사이드바 메뉴 클릭 → 해당 라우트 이동
```

### 4-5. 필터 변경 (PRD §3-4)
```
기간 칩 클릭 → 드롭다운 (오늘/이번주/이번달/분기/커스텀)
선택 → 4개 차트 + 3개 테이블 fetch 재호출 + URL query string 업데이트
요금제 칩 → 활성 테넌트 KPI + 요금제 분포 차트만 재필터
상태 칩 → 전체 테넌트 KPI + 최근 가입 테넌트 테이블만 재필터
```

### 4-6. Realtime 갱신 (PRD §9)
```
Supabase Realtime channel: realtime:tenants:operator
  → 신규 가입 INSERT → "전체 테넌트" / "활성 테넌트" KPI 즉시 +1
  → 해지 UPDATE → 카운트 -1
  → 토스트 "(주)XXX이(가) 가입했습니다"
realtime:tickets:operator
  → P0/P1 티켓 INSERT → "오픈 티켓" KPI + 토스트 (소리 옵션)
```

## 5. 반응형 매트릭스 (02-device-matrix.md OP-01: Web ✓ / PWA △ / Tauri ✓)

### Desktop (≥1024px) — 현재 HTML 기본
- KPI 7개 가로 1열 (`grid-template-columns: repeat(7, 1fr)`)
- 차트 4개 1열 (1.5 / 1.5 / 1 / 1 비율)
- 테이블 3개 1열 (1.2 / 1.2 / 1)

### Tablet (768~1024px)
- KPI 4 + 3 wrap
- 차트 2 + 2 wrap
- 테이블 1 + 1 + 1 (세로 스택 가능)

### PWA Mobile (≤768px) — △ 단순화
- KPI 카드 우선 (가로 스크롤 또는 2열 wrap)
- 차트 단순화 (Donut 1개만 + Line 1개)
- 테이블은 카드형 변환 (행마다 카드)
- 사이드바 → 햄버거 메뉴 → 전체 오버레이
- 헤더 검색바 숨김 (햄버거 메뉴 안 검색 항목)

`@media` 쿼리는 추후 별도 PR로 추가 (이번 와이어프레임 단계는 desktop 기준).
