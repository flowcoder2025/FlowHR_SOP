## 2. 상태 매트릭스 (5)

| 키 | state | 차단 사유 | 권장 액션 |
|---|-------|---------|---------|
| 1 | default | 일반 403 | 이전 화면 / 내 대시보드 |
| 2 | role | 역할 불일치 (ROLE_INSUFFICIENT) | 현재 역할/필요 역할 표시 + 내 대시보드 |
| 3 | tenant | 테넌트 불일치 (TENANT_MISMATCH, RLS) | 본인 회사 데이터만 가능 안내 |
| 4 | session | 세션 만료 (SESSION_EXPIRED) | 다시 로그인 + return_url 보존 (09-routing §5) |
| 5 | contact | 운영팀 문의 필요 (CONTACT_OPERATOR) | 티켓 생성 / 이메일 |

## 5. 라우팅 동선 (09-routing.md §4)

```
RLS 차단 / 권한 매트릭스 위반
  ↓
/forbidden?reason=role&from=/operator/tenants (또는 인라인)
  ↓
[차단 종류별 메시지 + 권장 액션 노출]
  ↓
사용자 클릭:
  ├── 이전 화면 (history.back)
  ├── 내 대시보드 (역할별 — operator → OP-01 / tenant → TA-01 / employee → EM-01)
  ├── 다시 로그인 (session 만료 시 + return_url 보존)
  └── 운영팀 문의 (OP-08 신규 티켓 또는 이메일)
```
