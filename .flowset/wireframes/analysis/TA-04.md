## 6. 권한 매트릭스 (Gherkin 정합)

- `tenant_super`: CRUD/E (전체 + 드래그 이동)
- `tenant_hr_admin`: CRU/E (삭제는 자식·구성원 0건 시만)

- `employee`: R (전체 조회, read-only) — 모든 액션 비활성

## 8. Phase 7 변환

- react-arborist 또는 react-complex-tree (트리 + 드래그앤드롭)
- shadcn/ui Form + react-hook-form (상세 편집)
- 드래그 이동: `POST /departments/:id/move` + optimistic update + 자식·직원 자동 갱신
- 구성원 이동 모달: shadcn/ui Dialog + 다중 선택 + select-wrap
- 부서장 자동완성: react-aria Combobox + employees 검색
- 권한 음성: middleware role check + 트리 read-only mode
- Realtime: `realtime:departments:tenant_id={id}` 구독 → 트리 invalidate
