## 5. API 매핑

```
GET  /api/v1/me/notifications?status&type&page
POST /api/v1/me/notifications/:id/read
POST /api/v1/me/notifications/read-all
POST /api/v1/me/notifications/subscribe         # PWA Web Push subscription 저장
```

## 6. 권한 매트릭스

- 모든 사용자 (employee/manager/hr/super): R/U 읽음 본인 (state=default)
- 다른 사용자의 notification_id로 GET → 403 (RLS `notifications.user_id = auth.uid()`)
- 알림 클릭 → 관련 화면 이동 + 자동 `read_status='read'` (Realtime broadcast 헤더 종 카운트 즉시 감소)
- 7일 미열람 + 카카오 채널 활성 → 자동 알림톡 폴백

## 7. 검증

- [ ] 5 상태 — default 혼합 / loading / empty / unread 2건만 / error
- [ ] 탭 2 — 전체 / 미읽음 + count 배지 + state 토글로 active 시각화
- [ ] 미읽음 row — is-unread (dot + bg 강조) + 읽음 row — 기본 스타일 차이
- [ ] 6 row 다양성 — 결재 2 (휴가 1차 / 근태 승인) + 문서 2 (급여 / 증명서) + 시스템 1 (점검) + 공지 1 (휴가 정책)
- [ ] 클릭 시 a href — EM-05 / EM-06 / EM-07 / 시스템 알림은 href 없음
- [ ] PWA 설치 안내 — info-bg + 설치 CTA → /install
- [ ] Playwright smoke — iconInvisible 0

## 8. Phase 7 변환

- TanStack Query — `/me/notifications` `useInfiniteQuery` (cursor 페이지)
- Realtime — `realtime:notifications:user-{id}` 구독 → 새 알림 즉시 prepend + 헤더 종 배지 갱신
- PWA Web Push — Service Worker `subscribe` + `users.push_subscription` 저장
- iOS 16.4+ — 홈화면 추가 (`A2HS`) 후만 푸시 가능 — 안내 + 설치 가이드 (CM-22 PWA 설치 안내)
- 카카오 폴백 — 발송 후 30분 미열람 cron → 카카오 알림톡 send
- 자동 읽음 — `<a>` 클릭 시 `useMutation('/read')` fire-and-forget + navigate
- 전체 읽음 — 낙관적 업데이트 (배지 즉시 0 + 모든 row read style)

## 9. 의존성

- **선행**: CM-15 (시스템 알림 발송 인프라)
- **연계**: 모든 화면 (알림 클릭 시 이동)
- **이벤트**: Realtime broadcast — 결재 / 근태 수정 / 문서 발행 / 시스템 점검
- **외부**: PWA Web Push API (iOS 16.4+ 홈화면 추가 필수), 카카오 알림톡 폴백, SMS (카카오 실패 시)
