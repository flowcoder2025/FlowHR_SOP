```
POST   /api/v1/tenant/api-keys/:id/rotate
```

## 6. 권한 매트릭스 (Gherkin 정합)

- `tenant_super`: CRUD/S/L 전체 (API Key 발급 포함)

## 8. Phase 7 변환

- 연동 카드 — Card grid (shadcn/ui) + 카카오 등 브랜드 SVG 로고
- 연결 모달 — shadcn/ui Dialog + API Key/Secret/채널ID 입력 + 테스트 발송 흐름
- API Key 발급 모달 — react-hook-form (사유 + 권한 select + 만료일 date) → 응답 키 한 번만 표시 (modal에 i-copy 강조)
- API Key 폐기 confirmation
- 로그 보기 — drawer + TanStack Virtual (대용량 호출 로그)
- 인증 정보 저장 — Supabase Vault 또는 컬럼 단위 암호화
- Realtime: `integrations:tenant_id={id}` channel — 연결/실패 상태 즉시 갱신
