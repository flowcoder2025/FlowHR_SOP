## 5. API 매핑

```
GET  /api/v1/me/approvals?status&type&page
GET  /api/v1/me/approvals/:id
POST /api/v1/me/approvals/:id/cancel
POST /api/v1/me/approvals/:id/resubmit             # 반려된 건 복사 → EM-03/08 등 prefill
```

## 6. 권한 매트릭스

- `employee`: R/Cancel/Resubmit 본인 (state=default)
- 다른 직원의 approval_id로 GET → 403 (RLS)
- 취소 가능 상태 — pending / in_progress (1차 승인 전까지)
- 재신청 — rejected 건만 → 원본 데이터 복사 + EM-03 (휴가) / EM-08 (증명서) / 본 화면 (정보변경) prefill
