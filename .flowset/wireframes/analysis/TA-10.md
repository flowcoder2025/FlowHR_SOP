```
GET   /api/v1/tenant/documents?type&status&from&to&page

POST  /api/v1/tenant/documents/bulk-send
```

## 8. Phase 7 변환

- shadcn/ui Tabs (orientation=horizontal) + URL ?tab=X
- 일괄 업로드: react-dropzone + SheetJS parse → POST /bulk-payroll
- PDF 생성: Puppeteer (서버) 또는 React-PDF (클라이언트) — Signed URL
- 발송 상태 Realtime: Supabase channel `documents:tenant_id={id}` 구독
- 미열람 cron: 발송 후 7일 미열람 → 자동 재발송 알림
- 삭제 confirmation: shadcn/ui Dialog + 사유 textarea 필수
