## 8. Phase 7 변환

- react-big-calendar 또는 자체 grid (overflow-x 모바일 처리)
- 캘린더 데이터 fetch: `GET /leaves/calendar` (병렬 직원 fetch 또는 단일 응답)
- 목록 ↔ 캘린더 뷰 토글 — URL ?view=calendar|list 동기화
- 휴가 부여 모달: react-hook-form + 직원 자동완성 + LeaveType select + 사유 textarea
- 잔여 현황 별도 탭 또는 drawer (Phase 7)
- 만료 cron — 매 1/1 expired 처리 + 만료 30일 전 알림
