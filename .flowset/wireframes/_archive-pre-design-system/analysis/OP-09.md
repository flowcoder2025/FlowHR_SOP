## 강력한 필터

- 기간은 **필수** (정책상 무한 조회 불가, 성능 보호)
- 이벤트 유형은 멀티 선택 + 와일드카드 (`auth.*`, `tenant.*` 등)
- 사용자/테넌트는 자동완성 입력
- "적용" 버튼 — 즉시 fetch + URL query string 갱신

## 상세 모달

- before/after JSON diff (좌: danger-bg, 우: success-bg)
- 메타: User-Agent, IP, 요청 ID, 테넌트
- 와이어프레임에 펼친 상태로 시각화 (`tenant.update` 예시)

## CSV 내보내기

- operator_super만 활성 (PRD §8 Scenario 5)
- 비동기 작업 → 완료 시 이메일 발송 또는 다운로드 링크 (대용량 10만 행 한도)

## 권한 분리

- 운영사: cross-tenant 전체 조회 (`/operator/audit-logs`)
- 테넌트 사용자: TA-13 회사 설정 > 감사 로그 탭 (자기 테넌트만)
- tenant_hr_admin이 `/operator/audit-logs` 직접 접근 → 403 (PRD §8 Scenario 6)
