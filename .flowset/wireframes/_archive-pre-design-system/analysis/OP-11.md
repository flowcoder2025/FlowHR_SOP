## 본 와이어프레임 = 보안 탭

다른 탭은 콘텐츠 영역 교체. 좌측 vertical tabs는 9개 모두 표시 (active 표시).

각 탭 콘텐츠:
- **기본정보**: 운영사 회사명/로고/연락처/사업자
- **운영자 계정**: super/staff 목록 + 초대 + 2FA 강제
- **보안 (현재)**: 비밀번호 정책 / 잠금 / 세션 / 2FA
- **메일**: SMTP 설정 + 테스트 발송
- **알림**: 카카오 채널 + NHN Cloud 키 + SMS + FCM
- **API**: 운영사 API 키 (멀티 + 만료)
- **데이터 보관**: audit_logs/attendances/leaves 보관 기간
- **백업**: 자동 일정 + 수동 트리거 + 이력
- **점검모드**: 토글 + 메시지 + 예약

## 인터랙션

- 탭 전환 → URL `?tab={key}` (브라우저 뒤로가기 보존)
- 변경 시 "저장" 버튼 활성, 미변경 시 disabled
- "테스트 발송" → 즉시 발송 + 결과 토스트
- 점검 토글 ON → 영향 받는 테넌트 / 활성 세션 수 표시 모달 → 확정 시 모든 비-operator → CM-06 리다이렉트 (PRD §8 Scenario 3)

## 권한

- operator_super: CRUDS/L 전권
- operator_staff: R 일부 → "운영자 초대" 비활성, 점검 토글 비활성 (PRD §8 Scenario 6)
