## 본 와이어프레임 = 보안 탭

직원 EM-09와 동등 + 운영사 보안 강화:
- 비밀번호 12자+ (직원 10자+ 강화)
- **2FA 비활성화 불가** (운영사 강제 정책)
- 활성 세션 강제 종료 강화 — super는 다른 운영사 사용자 세션 종료 가능

## 운영사 특수 기능 (KI-029 핵심)

### 다른 운영사 사용자 세션 강제 종료 (super 전용)
- "다른 운영사 사용자 세션 관리" 섹션에서 staff 목록 + "강제 종료" 버튼
- `POST /api/v1/operator/users/:id/force-logout` 호출 → audit_logs (action=force_logout)
- **마지막 active operator_super는 강제 종료 차단** (`409 OPERATOR_SUPER_LAST_REMAINING`) — 시스템 잠금 방지

### 이상 로그인 강조
- 최근 로그인 이력에서 해외 IP / 새 디바이스는 warning-bg + "(이상)" 라벨
- 본 wireframe: 2026-05-14 03:21 Tokyo 로그인 실패 → warning 강조

## 인터랙션

- 헤더 "프로필 사진 변경" → CM-09 파일 업로드 → users.avatar_url 갱신
- "비밀번호 변경" 클릭 → 모달 (현재/새/확인 + 정책 검증)
- "2FA 재발급" → 신규 QR + 6자리 검증 + 새 복구 코드 8개
- "다른 모든 세션 종료" → 본인 현재 세션 제외 모두 무효화
- 활동 탭 "다운로드 (Excel)" → CM-12 엑셀 내보내기 (audit_logs 본인 30일)

## 권한

- operator_super: 모든 액션 + 다른 운영사 세션 강제 종료
- operator_staff: 본인만 RU + 다른 사용자 세션 관리 섹션 표시 안 됨
