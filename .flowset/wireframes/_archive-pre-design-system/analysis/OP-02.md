## 글로벌 컴포넌트 (09-routing §6)

사이드바 / 헤더 (검색·도움말·종·프로필) / 푸터 — OP-01과 동일 일관 적용.

## 인터랙션 동선

- 회사명 클릭 → OP-03 테넌트 상세
- 행 액션 "상세 보기" → OP-03 / "상태 변경" → 모달 / "청구내역" → OP-06 (필터)
- "신규 테넌트 등록" → OP-04
- 검색 입력 → 자동 분기 (회사명/사업자번호/도메인/관리자명)
- 사이드 필터 변경 → URL query string + 테이블 즉시 갱신 + 카운트 표시

## Realtime

- `realtime:tenants:operator` UPDATE → 테이블 행 갱신 (상태 변경 시)
- 비활성화 → 해당 테넌트 사용자 모든 세션 즉시 무효화 broadcast

## 권한

- operator_super: 모든 액션 + "보관" 활성
- operator_staff: "보관" 비활성 (super only 표시)
- 기타 역할: `/forbidden` (라우팅 가드)
