## 마스터-디테일 레이아웃

- 좌측 (1fr): 티켓 목록 (선택 행 강조)
- 우측 (380px sticky): 선택 티켓 상세 + 응답 입력
- 모바일: 목록 → 상세 풀스크린 전환 (PWA 변형, 별도 wireframe)

## 응답 스레드 시각화

- user (회색 좌측 보더): 사용자 응답
- operator (파란 좌측 보더): 운영사 응답
- internal (노란 좌측 보더): 내부 메모 — 사용자에게 비공개 (PRD §8 Scenario 3)

## SLA 임박 알림

- P1 (2h) → 응답 시각 1h 50m 경과 시 담당자에게 "SLA 10분 임박" 알림 (PRD §8 Scenario 5)
