# 08. 성공 지표 (KPI / OKR)

## 1. North Star Metric

**활성 직원 수 (Weekly Active Employees, WAE)** — FlowHR이 직원의 일상에 얼마나 깊이 들어왔는지를 가장 잘 나타내는 단일 지표.

- 정의: 최근 7일 내 출퇴근 기록 또는 휴가/문서/알림 조회를 1회 이상 한 employee 수
- 측정: `daily_active_employees` 뷰 + 7일 윈도우 집계
- 목표: MVP+3개월 400명 / MVP+12개월 2,000명

## 2. 비즈니스 KPI

| 지표 | 정의 | MVP 출시 | MVP+3개월 | MVP+12개월 |
|------|------|---------|----------|-----------|
| MRR (Monthly Recurring Revenue) | 활성 구독 합계 | 100,000원 (베타 무료 3사 → 2사 유료 전환) | 1,250,000원 | 6,250,000원 |
| 유료 테넌트 수 | `subscriptions.status = 'active' AND paid` | 0 | 10 | 50 |
| 유료 사용자 수 | 활성 employees 합계 | 100 (베타) | 500 | 2,500 |
| 평균 테넌트 직원 수 (ARPT proxy) | `total_employees / total_tenants` | 33 | 50 | 50 |
| 해지율 (월간 Churn) | 이전월 대비 해지 테넌트 % | — | < 5% | < 3% |
| 영업 전환율 | 데모 → 계약 | — | 30% | 40% |
| CAC (고객 획득 비용) | 마케팅·영업 비용 / 신규 테넌트 | — | < 1,000,000원 | < 800,000원 |
| LTV (생애 가치) | ARPU × 평균 계약기간 | — | 2,500원 × 30명 × 12개월 = 900,000원 | 12개월 → 24개월 |

## 3. 제품 KPI

| 지표 | 정의 | 목표 |
|------|------|------|

| WAE / MAE 비율 | Weekly / Monthly Active | ≥ 0.6 (sticky) |
| 출퇴근 사용률 | 출퇴근 기록한 employee / 전체 active employee | ≥ 90% |
| 휴가 신청 디지털 비율 | 디지털 신청 / 전체 휴가 (종이 포함) | ≥ 95% |
| 결재 평균 처리 시간 | 신청 → 최종 승인까지 | ≤ 4시간 |
| 모바일(PWA) 사용 비율 | PWA / 전체 (Web + PWA + Tauri) | ≥ 50% |
| PWA 설치율 | 홈화면 설치 / 모바일 방문자 | ≥ 30% |
| Tauri Desktop 다운로드 | 신규 다운로드 / 전체 가입 관리자 | ≥ 40% |

## 6. 사용자 여정별 성공 지표

### J1. 신규 테넌트 온보딩
- 운영사 OP-04 → 완료까지: 평균 ≤ 2시간 (목표 1시간)
- 테넌트 첫 로그인 → 직원 1명 초대까지: 평균 ≤ 30분
- 직원 초대 → 첫 출퇴근까지: 평균 ≤ 24시간

### J2. 휴가 결재 (한직원 → 최팀장 → 이대표)
- 신청 → 첫 결재자 알림 도달: ≤ 30초
- 알림 도달 → 결재자 액션: 평균 ≤ 2시간 (업무시간)
- 신청 → 최종 승인: 평균 ≤ 4시간
- 잔여연차 자동 차감 정확도: 100% (분쟁 0건)

### J3. 급여명세서 배포
- 정인사 업로드 → PDF 생성 완료: ≤ 5분 (500명 기준)
- 일괄 발송 → 첫 직원 알림 수신: ≤ 1분
- 발송 후 24시간 내 열람율: ≥ 70%
- 발송 후 7일 내 열람율: ≥ 95%

## 7. OKR (분기별)

### MVP 출시 분기 (Q1 = 2026-Q4 가정)
- **Objective**: FlowHR MVP를 베타 3사에 안정 운영
  - KR1: 베타 고객 3사 계약 + LOI 확보 (현재 0)
  - KR2: 36 화면 중 MVP 27개 완성 (현재 0)
  - KR3: 베타 사용자 100명 활성화 (현재 0)
  - KR4: known-issues P0 0건 + 가용성 99.5% (현재 -)

### MVP+3개월 분기 (Q2)
- **Objective**: 베타 → 유료 전환 + 제품 안정화
  - KR1: 유료 테넌트 10사 (현재 0/3 베타)
  - KR2: 활성 사용자 500명 (현재 100)
  - KR3: MRR 1,250,000원 (현재 0)
  - KR4: CSAT 4.0 이상 (현재 -)

### MVP+12개월 분기 (Q5)
- **Objective**: 시장 점유 확대 + 후순위 기능 4종 추가
  - KR1: 유료 테넌트 50사 (현재 10)
  - KR2: MRR 6,250,000원 (현재 1.25M)
  - KR3: 전자계약/SSO/리포트 빌더/4대보험 자동계산 중 4종 출시 (현재 0)
  - KR4: NPS +30 (현재 -)
