# 00. 제품 개요

## 1. 제품 정체성

| 항목 | 내용 |
|------|------|
| 제품명 (가칭) | **FlowHR** |
| 카테고리 | 멀티테넌트 세팅형 HR 운영 SaaS |
| 한 줄 정의 | 소규모 사업장·중소기업이 직원·조직·근태·휴가·결재·급여·문서·증명서·알림을 한 시스템에서 운영하는 HR SaaS |
| 차별점 | 고객사 맞춤 초기 세팅(조직도/근무제/휴가정책/승인라인/문서양식)을 운영사가 직접 구축한 뒤 인당 저비용으로 운영 |

## 2. 시장 / 타깃

| 구분 | 정의 |
|------|------|
| 1차 타깃 | 직원 10~100명 규모의 중소기업 / 사업장 (음식점 체인, 소규모 제조, 디자인 스튜디오, 학원 등) |
| 2차 타깃 | 직원 100~500명 중견기업 (커스텀 모듈 도입 가능) |
| 비타깃 | 500명+ 대기업 (Workday/SAP/그룹웨어 통합 필요), 5명 이하 영세 사업장 (엑셀로 충분) |
| 지역 | 대한민국 (한글 first, 한국 노동법 준수) |

## 3. 가격 구조 (requirements.md / spec §2 인용)

| 항목 | 기준 |
|------|------|
| 초기 구축비 | 5,000,000원 (조직도·근무제·휴가정책·승인라인·문서양식 세팅) |
| 월 사용료 | 1인당 2,500원 |
| 최소 월사용료 | 없음 |
| 최소 계약기간 | 12개월 |
| 기본 유지보수 | 오류·장애 대응 중심 |
| 설정 변경 | 분기 1회 또는 월 1회 제한 |
| 추가 개발 | 1MD 700,000원 |
| 외부 연동 | 별도 견적 |

## 4. 핵심 가치 제안

| 페르소나 | 가치 |
|---------|------|
| 운영사 (당사) | 초기 구축비로 세팅 매출 + 인당 월 구독으로 안정 매출 |
| 테넌트 관리자 (HR 담당자) | 엑셀·종이 결재·카톡 공지를 한 시스템으로 통합. 노동법 위반 리스크 감소 |
| 직원 | 출퇴근·휴가·급여 조회를 모바일에서 원터치. 종이 결재 폐지 |

## 5. 제품 범위 (요약, 상세는 `06-mvp-scope.md`)

- **포함**: 멀티테넌트 운영, 직원/조직/근태/휴가/결재/급여명세서/문서/증명서/알림/감사 로그
- **MVP 후순위**: 전자계약 고도화, SSO, 출퇴근 기기 연동, 급여 자동계산, 고급 리포트, 커스텀 리포트 빌더, Webhook/API 공개
- **제외 (v1)**: 채용 ATS, 성과 평가(OKR/MBO), 교육 LMS, 워크플로우 빌더

## 6. 출시 목표 (요약, 상세는 `08-success-metrics.md`)

| 시점 | 목표 |
|------|------|
| MVP 출시 | 베타 고객 3사 (직원 합계 100명 이상) |
| MVP +3개월 | 유료 고객 10사 / 활성 사용자 500명 |
| MVP +12개월 | 유료 고객 50사 / 활성 사용자 2,500명 / MRR 6,250,000원 |
