## 핵심 요구사항 요약

### 제품 정의
소규모 사업장과 중소기업이 직원, 조직, 근태, 휴가, 결재, 급여명세서, 문서, 증명서, 알림을 하나의 시스템에서 관리하는 **멀티테넌트 HR 운영 SaaS**. 고객사 맞춤 세팅(조직도/근무제/휴가정책/승인라인/문서양식)을 초기 구축비로 제공하는 **세팅형 HR SaaS**.

### 디바이스 매트릭스 (사용자 확정, 2026-05-15)

| 클라이언트 | 대상 사용자 | 범위 | 기술 |
|-----------|----------|------|------|
| **Web (브라우저)** | 운영사, 테넌트 관리자, 직원 | 풀 기능 | Next.js 15 + Tailwind |
| **PWA (모바일 웹)** | 직원, 테넌트 관리자 | 풀 기능 (모바일 최적화) | Next.js PWA + Service Worker |
| **Desktop App (Tauri)** | 테넌트 관리자, 직원 | 풀 기능 + 데스크톱 통합 (트레이/단축키/다중창) | Tauri 2.x (Windows/Mac/Linux) |

**모바일은 PWA로 대응 — 네이티브 앱(iOS/Android) 미개발.**

3개 클라이언트는 동일 Next.js 코드베이스 + 동일 Supabase API를 공유. 세션·인증·권한 매트릭스 일관.

### PWA 알려진 제약 (필수 대응)

| 제약 | 대응 |
|------|------|
| iOS 푸시: 16.4+ + 홈화면 추가 필수 | 첫 진입 시 PWA 설치 가이드 모달 + 카카오 알림톡/SMS 폴백 채널 |
| iOS 백그라운드 위치 불가 | 출퇴근은 포그라운드 클릭 시점 GPS만, 자동 추적 X |
| 카메라/파일 권한 일부 제한 | 증빙 사진은 `input[capture]`, 첨부는 표준 file picker |
| 오프라인 동기화 제한 | 출퇴근 기록만 오프라인 큐, 나머지는 온라인 전제 |

### 화면 총 수: 36개 + 공통 15종
- 운영사: 11개 (OP-01 ~ OP-11)
- 테넌트 관리자: 14개 (TA-01 ~ TA-14)
- 직원: 11개 (EM-01 ~ EM-11)

### 권한 코드 (spec §9-1)
C(생성), R(조회), U(수정), D(삭제), A(승인/반려), E(내보내기), N(알림), S(설정), L(로그), X(접근불가)

### MVP 포함 범위 (spec §12-1)
- 운영사: 테넌트 관리, 요금제, 청구, 기능 권한, 지원 티켓
- 테넌트 관리자: 직원, 조직, 근태, 휴가, 결재, 급여명세서, 회사 설정
- 직원: 출퇴근, 휴가 신청, 요청 현황, 급여명세서 조회, 문서 조회
- 공통: 로그인, 알림, 파일 업로드, 엑셀 다운로드, 감사 로그

### MVP 후순위 (spec §12-2)
전자계약 고도화, SSO, 출퇴근 기기 연동, 급여 자동 계산, 고급 리포트, 커스텀 리포트 빌더, Webhook/API 공개
